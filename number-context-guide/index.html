Number Context Guide

Apply label, unit, basis, and time to limit what a number can mean before drawing any conclusion.

A number is not a fact on its own

A bare figure carries no meaning. It only becomes readable once you can state what it is, how it is measured, what it covers, and when it held. Those are the four contexts.

The four contexts

  • Label — ultramarine.

    What the number represents. A figure with no label has no meaning yet.

  • Unit — coral.

    What unit the number is measured in. A figure without a unit cannot be placed anywhere.

  • Basis — lemon.

    Which items, quantities, or conditions the number includes. The coverage, not the headline.

  • Time — violet.

    When the number held. A figure from another moment is a different figure.

Missing context means incomplete

If any one of the four is missing, the number is incomplete. The correct move is to mark the missing context “Not stated” — never to fill it in from another number or from a guess.

A number without its label, unit, basis, and time is a shape, not a measurement.

A worked reading

  1. Label: state what the figure represents.
  2. Unit: name the unit it is measured in.
  3. Basis: list which items, quantities, or conditions it includes.
  4. Time: record when it held, then leave anything missing as “Not stated.”
