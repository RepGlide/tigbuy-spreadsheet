About This Resource

A number-context method and numeric proof strip built around a shared TigBuy spreadsheet.

What this resource is

This is an independent informational and navigation resource for people who use a TigBuy spreadsheet. It offers four number contexts — label, unit, basis, and time — so every visible number is checked for meaning before any conclusion is drawn.

What this resource is not

This resource is not the official TigBuy website, and it is not affiliated with, endorsed by, or operated by TigBuy or Google. It is not a price comparator, a fee calculator, a review platform, a product database, a store, a QC certification, a shopping agent, or an order tracker.

The number-context method

Everything here follows four contexts. Ultramarine marks the label. Coral marks the unit. Lemon marks the basis. Violet marks the time. A number missing any of these is incomplete and stays marked “Not stated” — never filled in with a guess.

How to use it

  1. Open the shared Google Sheet to see the listing references.
  2. Browse the twelve product categories from the home page.
  3. Read the three guides before drawing conclusions from any number.
  4. Confirm the missing contexts at their source.

Numeric-reading example — no real price, fee, percentage, calculation, or verification.
